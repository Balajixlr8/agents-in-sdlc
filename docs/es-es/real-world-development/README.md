Explora GitHub Copilot a lo largo del ciclo de vida del desarrollo de software mediante escenarios realistas, una aplicación completa y un backlog compartido. Trabajarás de forma iterativa para planificar cambios, crear código, probar el comportamiento, revisar solicitudes de cambios y gestionar el trabajo con agentes.

## Escenario

Eres desarrollador en Tailspin Toys, una empresa ficticia que ofrece financiación colectiva para juegos de mesa con temática para desarrolladores. El backlog de tu equipo ya está registrado en incidencias de GitHub, listas para que las abordes. Incluye funciones como el filtrado y la paginación, además de mejoras de calidad como la accesibilidad y los estándares de programación.

## Elige tu entorno

GitHub Copilot te acompaña dondequiera que trabajes. Elige el entorno que mejor se adapte a tu forma de desarrollar. Cada taller comienza con su propia configuración y utiliza el escenario compartido de Tailspin Toys.

### [GitHub Copilot CLI][cli]

Usa el asistente con agentes desde el terminal. Trabaja con los modos Plan y Autopilot, instrucciones, aptitudes, agentes personalizados, Playwright MCP, Agent Merge y comandos de barra prácticos.

### [Aplicación GitHub Copilot][app]

Ejecuta sesiones paralelas de agentes, cambia los modos de sesión, colabora en Canvas y gestiona incidencias y solicitudes de cambios de GitHub desde la aplicación de escritorio.

### [Agente de nube de GitHub Copilot][cloud]

Asigna incidencias de GitHub a un agente asíncrono, guía su trabajo, supervisa el progreso y revisa las solicitudes de cambios que abre.

### [Visual Studio Code][vscode]

Usa GitHub Copilot en Visual Studio Code y GitHub Codespaces. Trabaja con el modo de agente de Copilot Chat, servidores MCP y agentes personalizados sin salir del editor.
